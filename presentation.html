expo-openclaw-chat

A minimal chat SDK that drops into any Expo app and connects it to an OpenClaw gateway.

3

Three lines to integrate

createChat + ChatProvider + open()

0

Zero backend to deploy

Your OpenClaw gateway IS the backend

📷

Vision built in

Send screenshots, agent sees your UI

This is it.

import { createChat } from "expo-openclaw-chat";

const chat = createChat({
  gatewayUrl: "wss://your-machine.ts.net",
  token: "your-auth-token",
});

export default function App() {
  return (
    <chat.ChatProvider>
      <YourApp />
      <Button onPress={() => chat.open()} />
    </chat.ChatProvider>
  );
}

What makes it tick

WebSocket v3

Full protocol with request/response tracking and event streaming

Ed25519 Identity

Cryptographic device pairing — like AirPods, but for your dev setup

Hot Reload Loop

Agent edits code, Metro reloads — you see the fix instantly

Auto-Reconnect

Exponential backoff with jitter. Your subway ride won't kill the session
